# 매장 데이터 모듈 (배라 AX PoC, ②모듈)

신제품 출시(새로운 맛, 콜라보, 캠페인) 후 매장 안 손님 반응을 보고 방향을 정하는 화면입니다.
모든 값은 합성 데이터이며 정확도는 검증하지 않았습니다. 상단에 "합성 데이터, 정확도 미검증" 배지가 항상 있습니다.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 타입 검사 후 빌드
```

스택: Vite, React 18, TypeScript, Tailwind CSS v4, shadcn 구조(`src/components/ui`), recharts, lucide-react.

## 구조: 출시, 반응, 결정

| 메뉴 | 내용 |
|---|---|
| 출시 현황 | 현재 판정과 이유, 반응 곡선(구간별 판정 색 띠), 날짜별 판정과 이유, 변화 알림, 의사결정 대기 |
| 매장 반응 분석 | 상권 카드, 정렬과 검색이 되는 매장 표, 상권 곡선 |
| 매장 동선 분석 | 매장별 도면 위 가상 동선, 출시 전후 비교, 이탈 파레토, 전체 분포 |
| 의사결정 관리 | 방향 판단(확대, 유지, 보완, 정리), 보완 요청, 레이더 유형 보정, 기록 |
| 개인정보 보호 | 데이터 흐름, 이벤트 검사기 |

날짜 슬라이더와 재생은 없습니다. 제품마다 **오늘 기준 현재 경과일(D+N)** 로 최신 상태까지 바로 보여 줍니다
(가상 신메뉴 D+5, 가상 콜라보 D+12, 가상 캠페인 D+18, `src/lib/data.ts`의 `SCENARIOS`). 상단에서 제품을 고르면 한 줄 설명이 옆에 나옵니다.
색 강조: D+N은 파란색, 변화량(%p)은 오르면 초록 내리면 빨강, 의사결정 대기는 파란 블록.

## 판정 규칙 (`src/lib/data.ts`의 `verdict`)

- 출시 후 3일 전에는 판단하지 않습니다.
- 확대: 평소보다 25% 이상이고 최근 3일 오르는 중. 또는 정점의 80% 이상을 유지.
- 보완: 구매 점검 매장이 3곳 이상이고 놓친 판매가 기대 판매의 8% 이상.
- 정리: 6일째부터 반응이 12% 아래로 식었거나, 25% 아래에서 계속 내려감.
- 그 외는 유지. 신뢰도는 근거 일수로 정합니다(7일 미만 낮음, 14일 미만 중간).
- 출시 유형마다 같은 선택지가 뜻하는 행동이 다릅니다(`DIR_MEANING`).

판정은 공개 근거가 없는 자체 가설입니다. 승인은 집행이 아니라 **결정 기록**이며, 이 브라우저(localStorage)에만 남습니다.

## 가상 카메라 동선 (`src/lib/floor.ts`)

가상 손님이 도면 위를 움직이고 → 존 진입, 이탈, 체류 이벤트 → 존 간 흐름과 0.5m 칸 체류로 집계 → 출시 전 평소와 비교해 규칙으로 해석합니다.
6초 미만으로 스친 것은 방문으로 세지 않습니다. 도면은 시연용 1종이며 실제 도입 시 매장별 실측 도면과 카메라 보정이 필요합니다.
개인별 동선은 실제 매장에서 매장 PC 밖으로 나가지 않는다는 전제입니다.

## 디자인

색상 토큰은 제공된 플랫폼 테마 그대로(`src/index.css`, 라이트와 다크). 한글용 Pretendard와 상태색 `--good`, `--bad`만 덧붙였습니다.
통계 카드는 제공된 `advanced-stats` 구조를 일반화해 브리프에 씁니다. `ClippedAreaChart`, `TimelineAnimation`은 제공 코드에 없어 새로 만들었습니다.
