# 트렌드 레이더 모델

네이버 데이터랩 주간 검색량(2016.1 ~ 2026.10, 키워드 79개)으로
"지금 급등한 키워드가 13주 뒤(이달의 맛 출시 시점)에도 수요가 남을까"를 예측한다.

- `BR_trend_radar_model.ipynb`: 분석 노트북 (Colab용). 학습 데이터 만들기, 모델 비교, 중요 변수, 곡선 군집화
- `export_radar.py`: 같은 계산으로 앱 화면 데이터 `src/lib/trend-data.ts` 생성
- `data/`: 데이터랩 원본 CSV (키워드별 최고 주 = 100)

다시 만들기 (레포 최상위에서):

```
pip install pandas numpy scikit-learn
python model/export_radar.py
```

## 요약
| | 균형 정확도 |
|---|---|
| 랜덤 포레스트 | 0.75 |
| 규칙 (뜨는 데 5주 이하면 못 버팀) | 0.60 |
| 찍기 | 0.50 |

키워드 단위 5묶음 교차검증 (처음 보는 키워드로 시험). 곡선 모양 군집(K-means 4묶음)은 규칙 유형과 89% 일치.
유형 이름(단발형, 완만형, 반복형)은 `src/lib/data.ts` 의 `ShapeName` 과 같다.
